# SOL Predictor

Прогноз **направления** SOL (вверх или вниз) на 1 ч, 4 ч, 12 ч и 1 день. Без точной цены. Только бесплатные данные, без сервера: GitHub Actions считает прогноз каждый час, GitHub Pages показывает Telegram Mini App.

Модель избирательная: по каждому горизонту она даёт вероятность роста, а сигнал выдаёт только когда уверена (примерно в 30% окон). В остальное время показывает «НЕТ СИГНАЛА». По-настоящему важна только живая точность на вкладке «Трек-рекорд».

**Не финансовый совет.** Инструмент не торгует и ничего не обещает.

## Схемы

| | Схема | Данные |
|---|---|---|
| A | Тренд и моментум от 1 ч до 4 недель | спот-свечи Binance |
| B | Открытый интерес, long/short, агрессивные покупки | архивы фьючерсов Binance (с задержкой 30 ч) |
| C | Премия perp/спот (из неё считается funding) | архивы фьючерсов Binance (с задержкой 30 ч) |
| D | Режим волатильности | спот-свечи |
| E | BTC и ETH как поводыри | спот-свечи |
| F | Стейблкоины на Solana | DefiLlama |
| G | Индекс страха и жадности | alternative.me |
| H | FOMC/CPI: сигнал не даём ±2 ч | `events.txt`, заполняется вручную |

## Команды

```bash
pip install -r requirements.txt
python test_backtest.py      # проверка на утечку будущего: на случайном блуждании должно быть ~50%
python backtest.py           # walk-forward: выбор на 2023–2024, честный результат на 2025→сейчас, пишет model.json
python predict.py --dry-run  # текущий прогноз в docs/data.json, без Telegram
```

## Запуск в Telegram (один раз)

1. Создать **публичный** репозиторий на GitHub и запушить в него эту папку.
2. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/docs`. Ссылка будет вида `https://<логин>.github.io/<репо>/`.
3. В Telegram у @BotFather: `/newbot` и сохранить токен. Затем `/setmenubutton`: выбрать бота, вставить ссылку из шага 2, текст «Прогноз».
4. Написать своему боту любое сообщение и открыть `https://api.telegram.org/bot<ТОКЕН>/getUpdates`. Число в `"chat":{"id":...}` — это chat id.
5. В репозитории Settings → Secrets and variables → Actions:
   - Secrets: `TG_TOKEN` (токен), `TG_CHAT` (chat id);
   - Variables: `APP_URL` (ссылка из шага 2).
6. Actions → `predict` → *Run workflow*. Дальше всё работает само, каждый час.

Раз в месяц-два полезно заново запускать `python backtest.py` локально и коммитить новый `model.json`.
